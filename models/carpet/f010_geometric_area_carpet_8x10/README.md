F010 is a modern living-room area carpet, 96 × 120 × 0.5 inches, modeled as a thin slab with a beveled binding edge and a diamond lattice in teal, rust, sand, and ivory (one Principled BSDF material slot per color so the pattern survives glTF export). From this folder, rebuild with Blender 4.2 LTS: `blender -b --factory-startup --python build.py -- --outdir .` — the script writes `model.glb`, `model.blend`, `preview.png`, and `metadata.json`.
