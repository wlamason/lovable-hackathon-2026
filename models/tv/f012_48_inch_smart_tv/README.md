F012 is a wall-mountable 48-inch class smart TV for the living room: a 43 in × 3 in × 26 in flat panel with a thin matte-black bezel, a slightly thicker rear housing, and no stand, so the bounding box is the panel itself. The glass is a separate dark glossy material named Screen. Rebuild from an empty scene with `blender -b --factory-startup --python build.py -- --outdir .` (Blender 4.2, bpy only); the script writes `model.glb`, `model.blend`, `preview.png`, and `metadata.json` beside itself.
