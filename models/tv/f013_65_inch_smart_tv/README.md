# F013 65-Inch Smart TV

Wall-mountable modern living-room TV panel with no stand: 57 in wide, 3 in deep, and 34 in tall. The 65 in glass is a 16:9 rectangle set behind a thin side and top bezel, with the extra height in a bottom chin and a small status light. The display is a separate dark glossy material named Screen so the web app can swap it. Rebuild from an empty scene with Blender 4.2: `blender -b --factory-startup --python build.py -- --outdir .`
