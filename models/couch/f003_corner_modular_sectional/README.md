F003 is a modern living-room corner modular sectional, 104 in wide by 72 in deep by 34 in tall: a charcoal track-arm run along X facing -Y, with a left chaise return along Y, loose seat and back cushions, and a recessed plinth. Rebuild from this folder with Blender 4.2 LTS: `blender -b --factory-startup --python build.py -- --outdir .` (the script writes `model.glb`, `model.blend`, `preview.png`, and `metadata.json` in meters, origin at the bottom center of the footprint).
