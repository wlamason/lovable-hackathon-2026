# F006 Tripod Corner Lamp

Scandinavian living-room floor lamp, 20 × 20 × 60 inches: three pale-oak legs in a corner stance (one leg toward the room, two toward the back corner) rise to a turned hub and carry a linen drum shade with brass ferrules, socket, and spider. Rebuild from an empty scene with `blender -b --factory-startup --python build.py -- --outdir <dir>` (Blender 4.2; default outdir is this folder). The script writes `model.glb`, `model.blend`, `preview.png`, and `metadata.json`.
