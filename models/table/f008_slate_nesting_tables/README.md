# F008 Slate Nesting Tables

Industrial living-room nesting set: three slate tops on black metal frames (large 32×20×18 in, medium 23×16×15.5 in, small 15.5×13.5×13.25 in), staggered so the smaller tables tuck under the larger ones. The nested arrangement fills 32 × 32 × 18 in (0.813 × 0.813 × 0.457 m), with the origin at the bottom center and the front facing -Y. Rebuild with Blender 4.2: `blender -b --factory-startup --python build.py -- --outdir .`
